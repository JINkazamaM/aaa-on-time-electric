# AAA On Time Electric

## Project Overview

**AAA On Time Electric** is a professional electrical contracting website built with modern web technologies. The site serves Florida statewide with 100% on-time service guarantee.

## Key Features

### Core Services
- **Commercial:** Panel upgrades, LED lighting, code inspections
- **Industrial:** High-voltage systems, machinery wiring, underground infrastructure
- **Residential:** Repairs, panel upgrades, rewiring, emergency service
- **Bucket Truck Service:** 60ft articulating bucket trucks for high-reach work

### Owned Equipment
- 60ft Articulating Bucket Truck (500lb capacity)
- Heavy Excavator for trenching and site prep
- Bobcat / Skid Steer for grading and conduit placement

### Website Features
- Interactive design with Framer Motion animations
- 10+ theme options (Dark Cyan, Light Sky, Purple Voltage, etc.)
- José Bot AI Assistant for instant customer support
- PDF estimate generation with digital signatures
- Progressive Web App (PWA) - installable and works offline
- Fully responsive design for all devices
- SEO optimized with meta tags and structured data

## Technical Stack

- **Framework:** React 18 with TypeScript
- **Build Tool:** Vite 6.x
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **PDF Generation:** jsPDF + html2canvas
- **AI Integration:** Google Gemini API

## Project Structure

```
├── public/                 # Static assets (images, icons, service worker)
├── src/
│   ├── components/         # React components
│   │   ├── sections/      # Page sections (Hero, Services, Equipment, etc.)
│   │   └── ...            # UI components (Layout, Footer, etc.)
│   ├── hooks/             # Custom React hooks
│   ├── utils/             # Utility functions
│   ├── constants.ts       # App constants
│   ├── types.ts           # TypeScript types
│   └── ...
├── dist/                  # Production build output
├── index.html            # Entry HTML file
└── package.json          # Dependencies and scripts

```

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
